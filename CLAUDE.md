# CLAUDE.md

Pygoscribe is a Rust + GTK4/libadwaita image markup app for the Ubuntu top
bar.

**Read `docs/PROJECT_CONTEXT.md` first.** It holds the goals, design decisions,
roadmap status and open items from earlier conversations. `README.md` covers
usage and installation.

## Quick facts

- App ID: `org.outram.Pygoscribe`. Use `org.outram.*` for any new IDs.
- Build and run: `cargo run --release`. Tests: `cargo test`.
- All packages: `./install.sh` (outputs in `dist/`). See `--help`.
- Releases: tag, push, then `scripts/release.sh v<version>`, which builds the
  .deb and the Flatpak bundle and attaches both, plus the source tarballs, to
  its release on **both GitHub and Gitea** (tokens `$PYGOSCRIBE` (GitHub) and `$GITEA`
  in `~/.profile`). Every release must ship all four files to both.
- Remotes: `origin` → `git@github.com:noutram/pygoscribe.git` (local `master`
  pushes to GitHub `main`), `pi5` → Gitea on Nick's pi5 (branch
  `master`; URL in `git remote -v`). Push to both.
- License: **GPL-3.0-only**, © 2026 Nicholas Outram (since 0.1.14). New files
  get the same two-line SPDX header as `src/main.rs` (copyright 2026 Nicholas
  Outram, GPL-3.0-only) or a `REUSE.toml` entry; `reuse
  lint` and `cargo deny check licenses` (allow-list in `deny.toml`) run in
  `install.sh` and must pass. `THIRD-PARTY-LICENSES.md` is generated by
  `cargo about` (template `about.hbs`); don't edit it by hand.
- **A binary never ships without its source tarballs next to it.**
  `scripts/release.sh` uploads `pygoscribe-<v>-src.tar.xz` (with vendored
  crates) and the Poppler tarball beside the .deb and .flatpak; a package
  passed on any other way (email, USB, another site) takes them along.
- Packaging targets are `.deb` (recommended) and Flatpak. Snap was abandoned;
  don't reintroduce it.
- Nick's default mail app is Proton Mail, which can't take attachments, so
  Email… falls back to a blank compose window plus the image on the clipboard.
  Keep that behaviour.
- Files shared with other apps go to `~/Pictures/Markup-Sent` (not a hidden
  folder, so snap and Flatpak apps can read it).
- When testing a rebuild, `pkill pygoscribe` first: a running tray instance
  otherwise receives the request.

## Wording

- No documentation mentions the app's earlier name or any other vendor's
  markup app (Nick, 14 Nov 2026). Describe the tools on their own terms.
  Code that has to know the old IDs (`src/migrate.rs`, the .deb
  `conflicts`, the Flatpak permission) keeps them.
